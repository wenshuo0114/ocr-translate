截屏识别翻译 — 怎么用
====================

在哪
  从 GitHub 下载或克隆后，打开那个文件夹，双击 start.bat。
  仓库：https://github.com/wenshuo0114/ocr-translate

启动
  双击 start.bat
  只开这一个窗口。关掉窗口，程序就结束。没有后台。
  界面是浅色：白底、蓝按钮，不再是一整片黑。
  中文变成 æä»l 那种是编码问题，已经修好。必须先关掉旧窗口，再双击 start.bat。旧窗口还在跑的是旧脚本。Key 要重填。

框选出译文（像划词那样，出在原处）
  点「截屏识别」或按截屏快捷键，在桌面拖一个框。没有全屏遮罩，不会白屏、也不会扫两下。Esc 取消。
  译文浮在你框的位置，不用先看大窗口。
  浮层上：译文 / 原文 / 复制 / 关闭。点文字可在译文和原文之间切。Esc 关闭浮层。
  复制免费，不收费、不限次数。和有道不一样。
  可以先不填 Key，只看框会不会出在原处。不填 Key 不会识字、也不会翻译。

要识字、要翻译时
  必须先在窗口里填 DeepSeek 或 Groq Key。这两个都比较有性价比，选一个填就能用。
  Key 只留在这个窗口里，不写文件、不进源码。关掉窗口就要重填。
  不要把 Key 发给别人，也不要写进 Git。

界面
  左边：原文原样。屏幕上的字照抄，连体程序名不拆（getUserName 还是 getUserName），方便对照代码。
  右边：译文。连体程序名会拆开翻译（getUserName → 获取用户名），用来检查 AI 给的代码。不要自己一个单词手拆。
  文件名、纯路径（System Volume Information、FirPE.exe）本来就不是句子，译文可能仍接近原名。
  点右边或点「回到原文」会回到左边。
  「译成哪国话」用上面的下拉框。不装各国语言包，靠 API 翻译。
  可分别复制原文、复制译文。

快捷键（可自己录）
  默认截屏：Ctrl+Shift+S
  呼出窗口：Ctrl+Shift+H（程序开着时，从别的软件按这组键把窗口唤到最前。关掉窗口就无效，没有后台。）
  复制原文：Ctrl+Shift+C
  复制译文：Ctrl+Shift+T
  回到原文：Ctrl+Shift+B
  点「录制」后，先按住 Ctrl 或 Shift 或 Alt，再按字母/数字/F1-F12。Esc 取消。
  录制时会暂时放开旧热键，否则系统把键吃掉，会录不进去。只保存按键，不保存 Key。
  录错或窗口打不开：再开一次 start.bat，点「恢复默认」。坏的快捷键不会再把程序卡死。

网络
  只请求这两个官网：
  https://api.deepseek.com
  https://api.groq.com
  没有别的回传。

核对代码
  就是为了看懂 AI 给的连体程序名。左边对照原文，右边看翻译。
  不要只框 System Volume Information、FirPE.exe 这种文件名，那不是句子。

改过之后
  必须先关掉窗口，再双击 start.bat。Key 要重填，不写进文件。
  右边若是 æä»l 这种乱码：关窗重开。已按 UTF-8 修过。

给朋友 / 公开
  只发这两个文件：OcrTranslate.ps1 、 start.bat ，外加这份说明。
  各人填自己的 Key。
  上架、收费：要有合法执照，再走审核。未审核前不售卖。
