# 截屏识别翻译

本机一个窗口，框选屏幕，**译文出在你画的框上**。  
复制原文、复制译文都免费，不限次数。

没有后台进程，没有本机网站，也不把 Key 写进文件。关掉窗口，程序就结束。

适合自己用，也适合发给朋友。不会做软件的人，可以走猪八戒网这类正规平台，请人代装或教怎么用。作者这边源码公开；上架收费要有合法执照和平台审核，未审核前不售卖。

## 怎么用

1. 下载本仓库，在 Windows 上双击 `start.bat`。只开这一个窗口。
2. 点「截屏识别」，或按 `Ctrl+Shift+S`，在桌面拖一个框。Esc 取消。
3. 桌面不会整屏变黑、也不会白屏闪两下。只出现你拖出来的框。
4. 可以先不填 Key，只看框会不会出在原处。不填 Key 不会识字、也不会翻译。
5. 要识字、要翻译，必须先在窗口里临时填自己的 DeepSeek 或 Groq Key。选一个填就能用。Key 不写文件。
6. 上面下拉框选「译成哪国话」。不装语言包，靠 DeepSeek / Groq 翻译。浮层上可以切「译文 / 原文」、复制、关闭。
7. 左边原文原样：连体程序名不拆（如 `getUserName`），方便对照代码。右边拆开翻译（获取用户名），用来检查 AI 给的代码。不要自己一个单词手拆。
8. 文件名、纯路径（`System Volume Information`、`FirPE.exe`）本来就不是句子，译文可能仍接近原名。
9. 中文变成 `æä»l` 那种是编码问题，已经修好。必须先关掉旧窗口，再双击 `start.bat`。Key 要重填。

更细的说明在 `使用说明.txt`。

## 快捷键（可自己改）

| 作用 | 默认 |
| --- | --- |
| 截屏 | Ctrl+Shift+S |
| 呼出窗口 | Ctrl+Shift+H |
| 复制原文 | Ctrl+Shift+C |
| 复制译文 | Ctrl+Shift+T |
| 回到原文 | Ctrl+Shift+B |

在窗口里点「录制」，先按住 Ctrl/Shift/Alt，再按字母、数字或 F1–F12。Esc 取消。录制时会暂时放开旧热键，避免录不进去。只保存按键，不保存 Key。

## Key 怎么处理

- 只留在这次打开的窗口里。
- 不写文件、不写注册表、不写日志、不进 Git。
- 关掉窗口就要重填。
- 各人用自己的 Key。不要把 Key 发给别人，也不要贴到聊天里。

## 识别习惯

- 左边原文按屏幕上的字来，代码名不拆开。例如 `getUserName` 保持原样，方便对照代码。
- 右边译文把连体名拆开翻译，例如 `getUserName` → 获取用户名。用来检查 AI 给的代码，不要自己一个单词手拆。
- 文件名、纯路径不是句子。`System Volume Information`、`FirPE.exe` 这类，译文可能仍接近原名。
