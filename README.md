# 截屏识别翻译

本机一个窗口，框选屏幕，**译文出在你画的框上**。  
复制原文、复制译文都免费，不限次数。

没有后台进程，没有本机网站，也不把 Key 写进文件。关掉窗口，程序就结束。

适合自己用，也适合发给朋友。不会做软件的人，可以走猪八戒网这类正规平台，请人代装或教怎么用。作者这边源码公开；上架收费要有合法执照和平台审核，未审核前不售卖。

## 怎么用

1. 下载本仓库，在 Windows 上双击 `start.bat`。
2. 点「截屏识别」，或按 `Ctrl+Shift+S`，在桌面拖一个框。Esc 取消。
3. 桌面不会整屏变黑、也不会白屏闪两下。只出现你拖出来的框。
4. 可以先不填 Key，只看框会不会出在原处。
5. 要识字、要翻译时，在窗口里临时填自己的 DeepSeek 或 Groq Key。这两个都比较有性价比，选一个填就能用。
6. 浮层上可以切「译文 / 原文」、复制、关闭。点文字也能在译文和原文之间切换。

更细的说明在 `使用说明.txt`。

## 快捷键（可自己改）

| 作用 | 默认 |
| --- | --- |
| 截屏 | Ctrl+Shift+S |
| 呼出窗口 | Ctrl+Shift+H |
| 复制原文 | Ctrl+Shift+C |
| 复制译文 | Ctrl+Shift+T |
| 回到原文 | Ctrl+Shift+B |

在窗口里点「录制」，再按下新的组合。只保存按键，不保存 Key。

## Key 怎么处理

- 只留在这次打开的窗口里。
- 不写文件、不写注册表、不写日志、不进 Git。
- 关掉窗口就要重填。
- 各人用自己的 Key。不要把 Key 发给别人，也不要贴到聊天里。

## 识别习惯

原文按屏幕上的字来，代码名不拆开。例如 `getUserName` 会保持原样，不会被拆成三个词。
