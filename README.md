# 截屏识别翻译

本机一个窗口。框选屏幕，译文出在原处。复制免费、不限次数。

**没有后台进程，没有本机网站，Key 不写进文件。**

## 怎么用

1. 下载本仓库。
2. Windows 上双击 `start.bat`。
3. 点「截屏识别」或按 `Ctrl+Shift+S`，拖一个框。
4. 要识字时，在窗口里临时填自己的 DeepSeek Key（Groq 选填）。关掉窗口，Key 就没了。

详细说明见 `使用说明.txt`。

## 网络

只请求：

- https://api.deepseek.com
- https://api.groq.com

## 给别人用

各人填自己的 Key。不要把 Key 发到网上，也不要写进 Git。

上架、收费需要合法执照和审核。未审核前不售卖。
