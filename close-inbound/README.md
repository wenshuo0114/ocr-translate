# 关入站

Windows 本机小工具。一次关掉入站放行（共享、网络发现、远程进站）。出站不改，网页还能上。

不提供远控。不帮别人装远控。不把机器交出去。各人在自己电脑上双击。

## 怎么用

1. 下载本目录。
2. 双击 `close-inbound.bat`。
3. 弹出管理员窗口时点「是」。
4. 看同目录 `close-inbound-result.txt`。`inbound-allow-still-on=0` 就是关好了。

中文文件名 `关入站.bat` 也是同一份，点哪个都行。

## 不要改的

- 不关出站。80 / 443 出站留给上网。
- 不要为了「名单好看」去删 Windows 内置用户。
- 不要写进别的软件当捆绑远控。
